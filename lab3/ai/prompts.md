### 3. Хибні відповідальності та вигаданий код у S6

- **Помилка AI:**

```
GradeService --> Controller: reject(GROUP_ENDED)

Groups --> GradeService : isGroupEnded(end_date)
```

- **Фідбек:**

```
типу так?
 GradeService -> GradeService : isMarkInRange(80) = true
 GradeService -> Groups : findById(group_id)
 activate Groups
 Groups --> GradeService : isGroupEnded(end_date)
 deactivate Groups
 GradeService -> GradeService : isGroupEnded(end_date) = true
 alt поточна дата пізніша за end_date (Groups.end_date)
   GradeService --> Controller : error("група завершена")
   note right of GradeService : updateGrade не викликається:\nmark = 70 і final_score = 70% лишаються без змін
 else група ще не завершена
```

- **Відповідь АІ:**

```
Майже, але один рядок лишився неправильним. Самовиклик `isGroupEnded(end_date) = true` ти додала правильно, а ось це ні:

Groups --> GradeService : isGroupEnded(end_date)

`Groups` не вміє перевіряти, чи група завершена. Вона лише віддає дані, тому повернення має бути таким самим, як у S1–S4:

Groups --> GradeService : group(end_date)

Тоді логіка читається так: `Groups` повертає `end_date`, а `GradeService` сам вирішує через `isGroupEnded(end_date)`.

Решту (guard `alt`, `error("група завершена")`, note) лишай як є. Далі йде `else` з `ref`, `gradeResult` і `deactivate GradeService` після `end`. Перевір, що вони на місці, бо ти скинула лише шматок.
```

- **Виправлено:** `401ff80`
